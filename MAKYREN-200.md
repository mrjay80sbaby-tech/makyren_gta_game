# MAKYREN-200 — Real Rigged Character: Quaternius Casual Male

- The two candidates from intake both failed as the hero: Kenney Animated Characters Protagonists is a chibi block-person with no walk clip (fails the repo's "no LEGO/block-person" rule); the Quaternius Casual Female is the wrong character for Ma'Kyren.
- Found and shipped instead: Quaternius "Casual Character" (Ultimate Modular Men Pack), CC0, via Poly Pizza (`https://poly.pizza/m/kZ3DmIoGip`, file `https://static.poly.pizza/90a9e2d4-053f-42f1-99a2-8f5e1180ea7f.glb`): 1.43 MB, ~1.86 m tall, 24 animation clips including Walk / Run / Idle, no external textures (vertex colours), validates clean.
- New `loadCharacter()` in `src/main.js`: loads the `character` slot (now `assets/character/casual_male.glb`), parents the GLB root to `playerRoot` at scale 1.0 (correct real-world scale next to the 4.5 m hero car — the old procedural capsule was ~3.4 m tall), hides the procedural body/head/hair/limbs on success, adds shadow casters, and maps the existing `MakyrenCharacterAnimator` walk/sprint/idle states onto the GLB's Walk/Run/Idle animation groups (procedural animator keeps running underneath, invisible). Procedural character stays as the fallback if the GLB fails.
- The unused Kenney + Quaternius-female GLBs are moved to `visual-004/assets/character/` (source-only, not shipped) — see MAKYREN-201.
- Known trade-off, recorded honestly: the GLB is 1.43 MB (over the 500 KB "same rule" for new assets) with no decimated LOD in v1 — it is a single instance, the hero, and it ships on all tiers including mobile so the A35 sees the real character too.
- Loader stops all 24 animation groups on load, then plays only the one the state machine wants: the FBX2glTF file arrived with the Death clip flagged playing, which would have fought the skeleton. Verified after the fix: only Idle plays while idle, only Walk while walking, back to Idle on stop.
- Verification: `node --check` + `npm run build` + smoke check pass; headless Chromium (`?quality=medium&debug=1`) reports `MakyrenCharacter {loaded:true, animations:[idle,run,walk]}`, animator state `walk` while moving; screenshot shows a correctly proportioned man walking toward the camera, facing the right way, next to the hero car.
